# 动作系统

## 概述

动作系统（Action System）是流程执行中的原子执行单元。每个 Action 封装一个具体的可执行操作，通过注册表管理，可以被流程定义通过名称引用。

## 核心架构

```
task/action/
├── base.py          # Action 抽象基类 + ActionResult
├── registry.py      # ActionRegistry 注册表
├── runner.py        # ActionRunner 执行器
├── builder.py       # Action 发现与注册构建器
├── builtin/         # 内置动作
│   ├── action_listen.py      # 等待用户输入
│   └── action_response.py    # 生成回复
└── custom/          # 自定义业务动作
    ├── shared.py              # 共享 API 工具
    ├── lookup_order_status.py # 查询订单状态
    ├── lookup_logistics.py    # 查询物流信息
    └── recommend_similar_products.py  # 推荐相似商品
```

## Action 接口

### 抽象基类

```python
class Action(ABC):
    name: str  # 动作名称，用于在流程定义中引用
    
    @abstractmethod
    async def run(self, state: DialogueState, action_kwargs: dict) -> ActionResult:
        """执行动作"""
        ...
```

### ActionResult

```python
@dataclass
class ActionResult:
    messages: list[BotMessage]   # 产生的机器人回复
    slot_updates: dict           # 需要更新的 Slot 键值对
```

## Action 注册与发现

### ActionRegistry

```python
class ActionRegistry:
    _actions: dict[str, Action]  # name → Action 实例
    
    def register(self, action: Action): ...
    def get(self, name: str) -> Action: ...
```

### 自动发现机制

`register_custom_actions()` 函数通过 Python 的 `pkgutil` 和 `inspect` 自动发现 `atguigu.task.action.custom` 包内所有 `Action` 子类并注册：

```python
def register_custom_actions(registry: ActionRegistry) -> None:
    package = importlib.import_module("atguigu.task.action.custom")
    for _, module_name, _ in pkgutil.iter_modules(package.__path__):
        module = importlib.import_module(f"atguigu.task.action.custom.{module_name}")
        for _, obj in inspect.getmembers(module, lambda o: isinstance(o, type) and issubclass(o, Action) and o is not Action):
            registry.register(obj())
```

**新增自定义 Action 只需**：
1. 在 `atguigu/task/action/custom/` 下新建 Python 文件
2. 定义继承 `Action` 的类，实现 `run` 方法
3. 系统启动时自动发现并注册

## 内置动作

### 1. ActionListen (`action_listen`)

**用途**：暂停流程执行，等待用户输入（无操作标记）。

```yaml
- id: listen
  type: action
  action: action_listen
```

**行为**：返回空的 `ActionResult`（无消息、无 Slot 更新）。`FlowExecutor` 检测到 `action_listen` 后会停止循环，保留当前流程上下文。

### 2. ActionResponse (`action_response`)

**用途**：生成机器人回复，支持三种模式。

#### 模式一：静态模板 (mode: `static`)

直接渲染 Jinja2 模板文本。

```yaml
- id: respond
  type: action
  action: action_response
  args:
    mode: static
    text: "订单{{ slots.order_number }}当前状态是：{{ slots.order_status }}。"
```

**可用变量**：
- `slots` — 当前流程的 Slot 字典
- `context` — 当前系统任务的上下文对象

#### 模式二：改写重述 (mode: `rephrase`)

先渲染推荐回复文本，再调用 LLM 进行自然语言改写。

```yaml
- id: respond
  type: action
  action: action_response
  args:
    mode: rephrase
    text: "看来我刚才理解偏了。你可以重新说一下你想查订单、查物流，还是申请退款吗？"
    prompt: |
      你是一个中文电商客服助手，语气自然、友好、简洁。
      请基于下面的建议回复，生成一句更自然的中文回复，保持原意，不要扩写。
      对话上下文：
      {{ history }}
      用户最后一句：
      用户：{{ user_message }}
      建议回复：{{ current_response }}
      改写后的回复：
```

**可用变量**（prompt 模板中）：
- `{{ history }}` — 格式化的对话历史
- `{{ user_message }}` — 当前用户消息
- `{{ current_response }}` — 渲染后的建议回复文本

#### 模式三：LLM 生成 (默认)

直接使用 `prompt` 参数调用 LLM 生成回复。

```yaml
- id: respond
  type: action
  action: action_response
  args:
    prompt: "基于以下信息生成回复：..."
```

## 自定义动作

### 1. LookupOrderStatusAction (`action_lookup_order_status`)

**用途**：查询订单状态。

```yaml
- id: lookup_order_status
  type: action
  action: action_lookup_order_status
  next: show_order_status
```

**执行逻辑**：
1. 从 `active_task.slots` 中获取 `order_number`
2. 调用商城 API：`GET /api/order/{order_number}`
3. 生成订单摘要文本
4. 设置 Slot 更新：`order_status`、`order_summary`

### 2. LookupLogisticsAction (`action_lookup_logistics`)

**用途**：查询物流信息。

```yaml
- id: lookup_logistics
  type: action
  action: action_lookup_logistics
  next: show_logistics
```

**执行逻辑**：
1. 从 `active_task.slots` 中获取 `order_number`
2. 调用商城 API：`GET /api/logistics/{order_number}`
3. 设置 Slot 更新：`tracking_number`、`logistics_company`、`logistics_status`

### 3. RecommendSimilarProductsAction (`action_recommend_similar_products`)

**用途**：推荐相似商品（预留状态）。

```yaml
- id: respond
  type: action
  action: action_recommend_similar_products
```

**当前行为**：返回提示消息"相似商品推荐功能正在开发中，敬请期待！"

## 共享 API 工具 (`shared.py`)

自定义动作中使用的 HTTP API 调用工具：

| 函数 | 说明 |
|------|------|
| `fetch_order(order_id)` | 查询订单详情 `GET /api/order/{order_id}` |
| `fetch_logistics(order_id)` | 查询物流信息 `GET /api/logistics/{order_id}` |
| `fetch_product(product_id)` | 查询商品详情 `GET /api/product/{product_id}` |
| `_build_order_summary(payload)` | 从订单数据构建摘要文本 |

API 的基础 URL 通过环境变量 `COMMERCE_API_BASE_URL` 配置。
