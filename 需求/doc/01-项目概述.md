# 项目概述

## 简介

**Atguigu 智能客服系统** 是一个面向电商场景的任务导向型智能对话系统。它基于大语言模型（LLM）进行对话回合规划，能够自动识别用户意图并执行对应的业务流程，包括订单查询、物流追踪、退款申请等电商客服场景。

系统采用 **Python 3.12+** 开发，基于 **FastAPI** 构建 Web 服务，使用 **LangChain** 与 LLM 交互，通过 **SQLAlchemy (async)** + **MySQL** 实现状态持久化。

## 核心能力

| 能力 | 说明 |
|------|------|
| 订单状态查询 | 根据订单号查询当前订单状态 |
| 物流追踪 | 根据订单号查询物流单号、物流公司和配送进度 |
| 退款申请 | 收集订单号和退款原因，提交退款申请 |
| 商品信息查询 | 查询商品详细信息 |
| 相似商品推荐 | 基于当前商品推荐相似商品（预留入口） |
| 闲聊应答 | 处理非任务的日常对话 |
| 转人工客服 | 将对话转接给人工客服 |

## 技术栈

| 技术 | 用途 |
|------|------|
| **Python 3.12+** | 开发语言 |
| **FastAPI** | Web API 框架 |
| **LangChain** | LLM 调用与结构化输出 |
| **SQLAlchemy 2.0 (async)** | 数据库 ORM |
| **aiomysql** | MySQL 异步驱动 |
| **Pydantic / pydantic-settings** | 数据校验与配置管理 |
| **httpx** | 异步 HTTP 客户端（调用商城 API） |
| **Jinja2** | 模板渲染（Action 响应生成） |
| **uvicorn** | ASGI 服务器 |
| **YAML** | 流程定义文件格式 |

## 启动方式

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 LLM_API_KEY 等配置

# 2. 安装依赖
uv sync

# 3. 启动服务
uv run python main.py
```

服务默认监听 `http://0.0.0.0:18082`，提供 REST API 接口。
