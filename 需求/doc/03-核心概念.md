# 核心概念

## 1. 领域消息 (Domain Messages)

### UserMessage
用户发送的消息，包含文本或结构化对象。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sender_id` | `str` | 发送者唯一标识 |
| `message_id` | `str` | 消息唯一标识 |
| `type` | `MessageType` | 消息类型：`TEXT` / `OBJECT` |
| `text` | `str | None` | 文本内容 |
| `object` | `MessageObject | None` | 结构化对象 |

### MessageObject
结构化对象，用于传递订单、商品等结构化数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | `str` | 对象类型（如 `order`、`product`） |
| `id` | `str` | 对象唯一标识 |
| `title` | `str | None` | 对象标题 |
| `attributes` | `dict` | 扩展属性键值对 |

### BotMessage
机器人回复消息，同样支持文本和结构化对象。

### ProcessResult
消息处理结果，包含机器人的回复消息列表。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sender_id` | `str` | 发送者 ID |
| `message_id` | `str` | 响应消息 ID |
| `messages` | `list[BotMessage]` | 机器人回复消息列表 |

## 2. 对话状态 (Dialogue State)

### DialogueState
整个对话系统的状态聚合根，按 `sender_id` 独立存储。

```
DialogueState
├── sender_id             # 发送者标识
├── active_task           # 当前活跃的用户任务（可选）
├── paused_tasks[]        # 被暂停的用户任务栈
├── active_system_task    # 当前活跃的系统任务（可选）
├── focused_object        # 用户当前聚焦的结构化对象
├── sessions[]            # 历史会话列表
├── current_session_id    # 当前会话 ID
└── pending_turn          # 处理中的待决回合
```

### Session
表示一次对话会话。

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | `str` | 会话 ID |
| `started_at` | `datetime` | 会话开始时间 |
| `last_activity_at` | `datetime` | 最后活动时间 |
| `closed_at` | `datetime | None` | 关闭时间 |
| `turns` | `list[Turn]` | 会话中的回合列表 |

### Turn
一个对话回合，包含用户消息和机器人回复。

| 字段 | 类型 | 说明 |
|------|------|------|
| `turn_id` | `str` | 回合 ID |
| `user_message` | `UserMessage` | 用户消息 |
| `bot_messages` | `list[BotMessage]` | 机器人回复 |

### FocusedObject
用户当前正在操作的结构化对象（如选中的订单卡片）。

**关键方法（DialogueState）**：

| 方法 | 说明 |
|------|------|
| `start_task(flow_id, name)` | 启动新的任务 |
| `end_active_task()` | 结束当前活跃任务 |
| `interrupt_active_task()` | 中断当前任务（压入暂停栈） |
| `resume_task(flow_id)` | 从暂停栈恢复指定任务 |
| `cancel_active_task()` | 取消当前任务 |
| `set_slots(slots)` | 设置当前任务的 Slot |
| `remove_slot(name)` | 移除指定 Slot |
| `start_session()` / `close_current_session()` | 会话生命周期管理 |
| `begin_turn(user_message)` / `commit_pending_turn()` | 回合生命周期 |
| `start_system_task(flow_id, name)` | 启动系统任务 |
| `end_system_task()` | 结束系统任务 |
| `set_focused_object(obj)` | 设置聚焦对象 |
| `reset_runtime_state_for_new_session()` | 新会话时重置运行时状态 |

## 3. 任务上下文 (Task Context)

### TaskContext
表示用户在执行业务流程时的上下文。

| 字段 | 类型 | 说明 |
|------|------|------|
| `flow_id` | `str` | 流程标识 |
| `step_id` | `str` | 当前步骤标识 |
| `slots` | `dict` | 流程收集的参数键值对 |

### SystemContext
表示系统级任务的上下文，有以下子类型：

| 子类 | 对应流程 | 说明 |
|------|----------|------|
| `StartedSystemContext` | `system_task_started` | 新任务启动 |
| `InterruptedSystemContext` | `system_task_interrupted` | 任务被打断 |
| `CanceledSystemContext` | `system_task_canceled` | 任务被取消 |
| `ResumedSystemContext` | `system_task_resumed` | 任务被恢复 |
| `CollectSystemContext` | `system_collect_information` | 收集 Slot 信息 |

## 4. 回合规划 (Turn Plan)

### TurnPlan
LLM 对当前用户消息的规划结果，决定响应策略。

```python
class TurnPlan(BaseModel):
    task: TaskTurnPlan | None = None      # 任务赛道
    knowledge: KnowledgeTurnPlan | None = None  # 知识赛道
    chitchat: ChitchatTurnPlan | None = None    # 闲聊赛道
```

- **规则**：同一回合只能有一个赛道非空
- **Task 赛道**：需要执行业务流程（查订单、查物流等）
- **Knowledge 赛道**：需要查询知识库信息
- **Chitchat 赛道**：纯闲聊或问候

### 赛道类型

**TaskTurnPlan**
| 字段 | 类型 | 说明 |
|------|------|------|
| `commands` | `list[dict]` | 状态变更命令列表 |

**KnowledgeTurnPlan**
| 字段 | 类型 | 说明 |
|------|------|------|
| `intents` | `list[str]` | 知识意图 ID 列表 |

**ChitchatTurnPlan**
| 字段 | 类型 | 说明 |
|------|------|------|
| (无附加字段) | | 仅表示归入闲聊赛道 |

### ClarifyReason
当规划无效时，LLM 需要返回澄清原因。

| 枚举值 | 说明 |
|--------|------|
| `MISSING_TRACK` | 没有选择任何赛道 |
| `MULTIPLE_TRACKS` | 同时选择了多个赛道 |
| `MISSING_TASK_COMMANDS` | 任务赛道缺少命令 |
| `MISSING_KNOWLEDGE_INTENT` | 知识赛道缺少意图 |
| `MISSING_FOCUSED_OBJECT` | 知识意图需要聚焦对象但未提供 |
| `OBJECT_REQUIRES_INTENT` | 对象消息但缺少意图 |

## 5. 流程 (Flow)

### Flow
一组有序步骤构成的业务流程，定义在 YAML 配置文件中。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `str` | 流程唯一标识 |
| `name` | `str` | 流程展示名称 |
| `description` | `str` | 流程描述 |
| `steps` | `list[FlowStep]` | 流程步骤列表 |
| `slots` | `list[FlowSlot]` | 流程使用的 Slot 定义 |

### FlowSlot
流程中需要收集的参数定义。

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `str` | Slot 名称 |
| `type` | `str` | 参数类型 |
| `label` | `str` | 展示标签 |
| `description` | `str` | 描述 |

### FlowStep
流程中的单个步骤。包含以下子类型：

| 步骤类型 | 说明 |
|----------|------|
| `start` | 流程起始步骤 |
| `action` | 执行一个 Action |
| `collect` | 收集用户输入的一个 Slot 值 |
| `end` | 流程结束步骤 |

### FlowStepLink
步骤之间的跳转关系。

| 链接类型 | 说明 |
|----------|------|
| `StaticLink` | 静态跳转到指定步骤 |
| `ConditionalLink` | 条件跳转（满足条件时） |
| `FallbackLink` | 兜底跳转（无条件匹配时） |

---

## 6. 动作 (Action)

### Action
流程中的原子执行单元，接收状态和参数，返回执行结果。

```python
class Action(ABC):
    name: str
    
    @abstractmethod
    async def run(self, state: DialogueState, action_kwargs: dict) -> ActionResult: ...
```

### ActionResult
动作执行结果。

| 字段 | 类型 | 说明 |
|------|------|------|
| `messages` | `list[BotMessage]` | 动作生成的回复消息 |
| `slot_updates` | `dict` | 动作设置的 Slot 更新 |

---

## 7. 知识查询 (Knowledge)

### KnowledgeIntent
知识查询意图定义。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `str` | 意图唯一标识 |
| `description` | `str` | 意图描述 |
| `provider_ids` | `list[str]` | 需要调用的知识提供者 ID 列表 |
| `requires_object` | `bool` | 是否依赖聚焦对象 |

### KnowledgeProvider
知识检索提供者的抽象接口。

| 提供者 | ID | 说明 |
|--------|-----|------|
| `ProductAPIProvider` | `api.product` | 从商城 API 查询商品信息 |
| `OrderAPIProvider` | `api.order` | 从商城 API 查询订单+物流信息 |
| `FAQProvider` | `faq.default` | FAQ 知识库（当前返回空结果） |
| `RAGProvider` | `rag.default` | RAG 检索增强生成（预留） |

---

## 8. 命令 (Command)

用于修改对话状态的操作指令，作为 Task 赛道中 `TurnPlan.commands` 的具体内容。

| 命令 | 说明 |
|------|------|
| `StartFlowCommand` | 启动指定流程 |
| `SetSlotsCommand` | 设置当前任务的 Slot 值 |
| `CancelFlowCommand` | 取消当前流程 |
| `ResumeFlowCommand` | 恢复暂停的流程 |
