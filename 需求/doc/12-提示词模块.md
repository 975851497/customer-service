# 提示词模块

## 概述

提示词模块（Prompts Module）集中管理所有与 LLM 交互的提示词模板，采用 Jinja2 模板引擎，避免提示词硬编码在业务代码中。

## 模块结构

```
atguigu/prompts/
├── __init__.py            # 模块初始化
├── prompt_loader.py       # 提示词模板加载器
├── history_builder.py     # 对话历史格式化工具
└── jinja2/                # 提示词模板文件目录
    ├── turn_plan.jinja2           # 回合规划提示词
    ├── knowledge_respond.jinja2   # 知识问答提示词
    ├── chitchat_respond.jinja2    # 闲聊回复提示词
    └── clarify_respond.jinja2     # 澄清回复提示词
```

## 提示词加载器 (PromptLoader)

`prompt_loader.py` 提供提示词文件的加载功能：

```python
def load_prompt(file_name: str) -> Template:
    """从 prompts/jinja2/ 目录加载 .jinja2 模板文件
    
    Args:
        file_name: 模板文件名（不含路径）
        
    Returns:
        Jinja2 Template 对象
    """
```

**使用示例**：

```python
template = load_prompt("turn_plan.jinja2")
prompt = template.render(
    history=history_text,
    user_message=user_message.text,
    available_flows=flows_json,
    active_task=active_task_info,
    interrupted_tasks=interrupted_tasks_info,
    focused_object=focused_object_info,
    knowledge_intents=intents_json
)
```

## 历史构建器 (HistoryBuilder)

`history_builder.py` 负责将对话的回合列表转换为 LLM 可读的文本格式。

### `build(turns)` 方法

```python
class HistoryBuilder:
    @staticmethod
    def build(turns: list[Turn]) -> str:
        """将回合列表格式化为 USER:/BOT: 文本
        
        Args:
            turns: 对话回合列表
            
        Returns:
            格式化后的历史文本
        """
```

### 格式化规则

**文本消息**：
```
USER: 你好，帮我查一下订单
BOT: 好的，我来帮你查询订单信息。
```

**对象消息**：
```
USER: [订单对象 id=123456, title=订单 #123456, ...]
BOT: 好的，订单123456的信息已经查到。
```

- 文本消息直接显示用户消息原文
- 对象消息以 `[对象类型 id=..., title=..., ...]` 格式显示
- 每条消息独占一行，以 `USER:` 或 `BOT:` 前缀

## 提示词模板详解

### 1. 回合规划模板 (`turn_plan.jinja2`)

**用途**：分析用户消息，决定当前回合的应答策略（任务/知识/闲聊/澄清）。

**模板变量**：

| 变量 | 说明 |
|------|------|
| `{{ history }}` | 对话历史文本 |
| `{{ user_message }}` | 当前用户消息 |
| `{{ available_flows }}` | 可用的业务流程列表（JSON） |
| `{{ active_task }}` | 当前活跃任务信息（JSON） |
| `{{ interrupted_tasks }}` | 已暂停的任务信息（JSON） |
| `{{ focused_object }}` | 用户聚焦对象信息（JSON） |
| `{{ knowledge_intents }}` | 可用的知识意图列表（JSON） |

**输出格式**：结构化的 JSON（使用 LangChain `JsonOutputParser` 解析为 `TurnPlan`）

### 2. 知识问答模板 (`knowledge_respond.jinja2`)

**用途**：基于检索到的知识块生成回复。

**模板变量**：

| 变量 | 说明 |
|------|------|
| `{{ history }}` | 对话历史 |
| `{{ user_message }}` | 用户消息文本 |
| `{{ knowledge_content }}` | 检索到的知识内容（合并后的文本） |

### 3. 闲聊回复模板 (`chitchat_respond.jinja2`)

**用途**：生成非任务型对话的回复。

**模板变量**：

| 变量 | 说明 |
|------|------|
| `{{ history }}` | 对话历史 |
| `{{ user_message }}` | 用户消息文本 |

### 4. 澄清回复模板 (`clarify_respond.jinja2`)

**用途**：将预定义的澄清消息改写为自然语言。

**模板变量**：

| 变量 | 说明 |
|------|------|
| `{{ clarify_message }}` | 预定义的澄清建议文本 |

## 设计原则

1. **集中管理**：所有提示词集中在 `prompts/jinja2/` 目录下，便于统一审查和优化
2. **模板化**：使用 Jinja2 模板引擎，支持变量注入，避免字符串拼接
3. **分离关注点**：提示词内容与业务逻辑分离，非开发者也能修改提示词
4. **可扩展**：新增提示词只需在 `jinja2/` 目录添加文件，通过 `load_prompt()` 加载

## 扩展提示词

如需新增一个提示词模板：

1. 在 `prompts/jinja2/` 目录下新建 `.jinja2` 文件
2. 编写 Jinja2 模板内容
3. 在业务代码中使用 `load_prompt("your_template.jinja2")` 加载

```python
from atguigu.prompts.prompt_loader import load_prompt

template = load_prompt("your_template.jinja2")
prompt = template.render(your_variable="value")
```
