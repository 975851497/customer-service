# 配置与部署

## 环境要求

| 依赖 | 版本要求 |
|------|----------|
| Python | >= 3.12 |
| MySQL | 8.0+（需要支持 utf8mb4 字符集） |
| uv | 最新版本 |

## 环境变量配置

### 配置模板 (`.env.example`)

```ini
# LLM 配置
LLM_MODEL=qwen-plus                    # LLM 模型名称
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1  # API 地址
LLM_API_KEY=<API_KEY>                  # API 密钥

# 商城 API 配置
COMMERCE_API_BASE_URL=http://127.0.0.1:18081  # 商城系统 API 地址

# 数据库配置
DATABASE_URL=mysql+aiomysql://atguigu:Atguigu.123@127.0.0.1:3306/customer_service?charset=utf8mb4

# 服务器配置
APP_HOST=0.0.0.0                       # 服务监听地址
APP_PORT=18082                         # 服务监听端口
```

### 配置解析

配置通过 `pydantic-settings` 自动从 `.env` 文件加载到 `Settings` 对象（定义在 `atguigu/conf/config.py`）：

```python
class Settings(BaseSettings):
    llm_api_key: str           # LLM_API_KEY
    llm_model: str             # LLM_MODEL
    llm_base_url: str          # LLM_BASE_URL
    database_url: str          # DATABASE_URL
    commerce_api_base_url: str # COMMERCE_API_BASE_URL
    app_host: str              # APP_HOST
    app_port: int              # APP_PORT
    
    model_config = SettingsConfigDict(env_file=ENV_FILE)
```

### 配置说明

#### LLM 配置

| 变量 | 说明 |
|------|------|
| `LLM_MODEL` | 使用的 LLM 模型名称。系统兼容 OpenAI 格式的 API，可对接通义千问、DeepSeek 等国产模型 |
| `LLM_BASE_URL` | API 基础地址，推荐使用兼容 OpenAI SDK 格式的国内镜像 |
| `LLM_API_KEY` | API 密钥 |

**推荐模型**：
- **通义千问 (阿里云 DashScope)**：`qwen-plus` / `qwen-max`，国内访问稳定
- **DeepSeek**：`deepseek-chat`

#### 商城 API 配置

| 变量 | 说明 |
|------|------|
| `COMMERCE_API_BASE_URL` | 商城后端的 API 地址，用于查询订单、物流、商品等数据 |

系统通过 `http_client` 调用以下商城 API：

| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/order/{order_id}` | GET | 查询订单详情 |
| `/api/logistics/{order_id}` | GET | 查询物流信息 |
| `/api/product/{product_id}` | GET | 查询商品信息 |

#### 数据库配置

| 变量 | 说明 |
|------|------|
| `DATABASE_URL` | MySQL 异步连接 URL，使用 `aiomysql` 驱动 |

格式：`mysql+aiomysql://用户:密码@主机:端口/数据库名?charset=utf8mb4`

**数据库表结构**：

```sql
CREATE TABLE dialogue_states (
    sender_id VARCHAR(255) PRIMARY KEY,
    state_json TEXT NOT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> 表由 SQLAlchemy ORM 自动创建（通过 `Base.metadata.create_all` 实现），无需手动建表。

#### 服务器配置

| 变量 | 说明 |
|------|------|
| `APP_HOST` | 监听地址，`0.0.0.0` 表示监听所有网络接口 |
| `APP_PORT` | 监听端口，默认为 `18082` |

## 部署步骤

### 1. 基础环境

```bash
# 安装 Python 3.12+
# 建议使用 pyenv 或 conda 管理版本

# 安装 uv（Python 包管理器）
# Windows (PowerShell):
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS / Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. 项目部署

```bash
# 克隆项目
git clone <repository_url> customer-service
cd customer-service

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入实际的 API_KEY 和数据库配置

# 安装依赖
uv sync

# 初始化数据库（需要先创建 MySQL 数据库）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS customer_service CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 启动服务
uv run python main.py
```

### 3. 验证部署

```bash
# 发送测试消息
curl -X POST "http://127.0.0.1:18082/api/chat" \
  -H "Content-Type: application/json" \
  -d '{"sender_id": "test_user", "text": "你好"}'
```
