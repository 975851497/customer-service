# 状态管理与持久化

## 概述

系统的对话状态管理采用 **全量序列化** 策略：每次对话交互时，将完整的 `DialogueState` 对象从数据库加载到内存，处理完成后全量写回。状态以 JSON 格式存储在 MySQL 中。

## 状态持久化架构

```
┌─────────────────────────────────────────────────────┐
│                   业务层                              │
│                                                     │
│  DialogueService.process_message()                   │
│     │                                               │
│     ├── DialogueStateRepository.load_state(id)      │
│     │      │     ← MySQL → dialogue_states 表       │
│     │      └── JSON → DialogueState (反序列化)      │
│     │                                               │
│     ├── DialogueEngine.process_message(state, msg)  │
│     │      └── 修改 state 对象                      │
│     │                                               │
│     └── DialogueStateRepository.save_state(state)   │
│            │     ← MySQL → dialogue_states 表       │
│            └── DialogueState → JSON (序列化)        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 数据模型

### ORM 模型 (`models/dialogue_state.py`)

```python
class DialogueStateRecord(Base):
    __tablename__ = "dialogue_states"
    
    sender_id: str = Column(String(255), primary_key=True)
    state_json: str = Column(Text, nullable=False)
```

- **主键**：`sender_id`（每个用户一条记录）
- **`state_json`**：存储完整的 `DialogueState` 序列化 JSON

## 会话生命周期

### 会话超时

```python
# DialogueEngine._prepare_session() 中的超时检测
IDLE_TIMEOUT = 3600  # 1 小时

if current_session:
    idle_seconds = (now - current_session.last_activity_at).total_seconds()
    if idle_seconds > IDLE_TIMEOUT:
        # 关闭当前会话，创建新会话
        state.close_current_session()
        state.reset_runtime_state_for_new_session()
        state.start_session()
```

- 超时时间：**1小时**（3600秒）
- 超时时自动关闭旧会话，创建新会话，并重置运行时状态

### 新会话重置

```python
def reset_runtime_state_for_new_session(self):
    """新会话时重置运行时状态"""
    self.active_task = None
    self.paused_tasks = []
    self.active_system_task = None
    self.focused_object = None
    self.pending_turn = None
```

## 命令处理与状态变更

### CommandProcessor

命令处理器通过修改 `DialogueState` 的领域方法来变更状态：

```python
class CommandProcessor:
    async def run(self, commands: list[Command], state: DialogueState) -> None:
        for command in commands:
            if isinstance(command, StartFlowCommand):
                if state.active_task:
                    # 有活跃任务 → 中断当前任务
                    state.interrupt_active_task()
                state.start_task(command.flow_id, command.flow_name)
                state.start_system_task("system_task_started", flow_name)
                
            elif isinstance(command, SetSlotsCommand):
                state.set_slots(command.slots)
                
            elif isinstance(command, CancelFlowCommand):
                state.cancel_active_task()
                state.start_system_task("system_task_canceled", ...)
                
            elif isinstance(command, ResumeFlowCommand):
                # 如果当前有活跃任务且不是要恢复的 → 中断
                if state.active_task and state.active_task.flow_id != command.flow_id:
                    state.interrupt_active_task()
                state.resume_task(command.flow_id)
                state.start_system_task("system_task_resumed", ...)
```

### 任务栈管理

```
状态变更过程示例：

初始状态:
  active_task = None
  paused_tasks = []

1. 用户: "查订单12345"
   → StartFlowCommand("order_status_query")
   → active_task = Task(order_status_query)
   → paused_tasks = []

2. 用户: "先查物流67890"
   → StartFlowCommand("logistics_tracking")
   → 中断当前任务: interrupted = active_task
   → active_task = Task(logistics_tracking)
   → paused_tasks = [interrupted]

3. 用户: "回到订单查询"
   → ResumeFlowCommand("order_status_query")
   → active_task = popped from paused_tasks
   → paused_tasks = []
```

## 依赖注入

状态管理模块的依赖关系：

```
DialogueService
  ├── DialogueEngine          (单例，应用启动时构建)
  └── DialogueStateRepository (每次请求创建)
        └── AsyncSession      (每次请求创建)
```

在 FastAPI 中通过依赖注入管理生命周期：

```python
# 单例：引擎
def init_dialogue_engine():
    global _dialogue_engine
    _dialogue_engine = build_dialogue_engine()

# 每次请求：数据库会话 + 仓库 + 服务
async def get_db():
    async with database.session_factory() as session:
        yield session

async def get_repository(db: AsyncSession = Depends(get_db)) -> DialogueStateRepository:
    return DialogueStateRepository(db)

async def get_dialogue_service(
    engine: DialogueEngine = Depends(get_engine),
    repository: DialogueStateRepository = Depends(get_repository),
) -> DialogueService:
    return DialogueService(repository, engine)
```
