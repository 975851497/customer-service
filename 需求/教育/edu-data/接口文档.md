# Edu Data API 接口文档

## 概述

### 基础信息

| 项目 | 说明 |
|------|------|
| 服务名称 | Edu Data API |
| 版本 | 0.1.0 |
| 基础路径 | `http://<host>:8000/api/v1` |
| 交互文档 | `http://<host>:8000/docs` |

### 认证方式

所有需要用户身份的接口通过请求头 `X-User-Id` 传递当前登录用户 ID：

```http
X-User-Id: 1
```

- **必填接口**：缺失或无效时返回 401 `MISSING_USER_ID`
- **可选接口**：公共查询可不传，传入时必须为合法且启用的用户 ID

### 统一响应格式

**成功响应：**

```json
{
  "code": 0,
  "message": "ok",
  "data": { ... }
}
```

**失败响应：**

```json
{
  "code": "ERROR_CODE",
  "message": "错误描述",
  "data": null
}
```

### 通用 HTTP 状态码

| 状态码 | 含义 | 常用错误码 |
|--------|------|-----------|
| 200 | 成功 | - |
| 400 | 请求参数错误 | `INVALID_XXX`、`VALIDATION_ERROR` |
| 401 | 未认证 | `MISSING_USER_ID`、`INVALID_USER_ID` |
| 404 | 资源不存在 | `XXX_NOT_FOUND` |
| 409 | 业务冲突 | `ORDER_NOT_CANCELABLE`、`COUPON_EXPIRED` |
| 422 | 参数校验失败 | `VALIDATION_ERROR` |
| 501 | 未实现 | `NOT_IMPLEMENTED` |

### 分页参数

所有列表接口统一使用以下分页参数：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `pageNo` | int | 1 | 页码，从 1 开始 |
| `pageSize` | int | 20 | 每页条数，范围 1~100 |

分页响应结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [...],
    "pageNo": 1,
    "pageSize": 20,
    "total": 100
  }
}
```

```json
  }
}
```

### GET /api/v1/me/student-profile

获取当前用户的学员档案信息。

- **X-User-Id**：必填
- **learnerIdentity**：学习者身份（如 `k12_student`）
- **learningGoal**：学习目标
- **educationLevel**：学历层次（可能为 null）
- **grade**：年级（可能为 null）

**响应示例：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "studentId": 1,
    "learnerIdentity": { "code": "k12_student", "name": "K12学生" },
    "learningGoal": { "code": "score_improvement", "name": "提分提能" },
    "educationLevel": null,
    "grade": { "code": "grade_8", "name": "八年级" },
    "schoolName": "第一中学",
    "profileNote": null
  }
}
```

```json
{
  "code": 0,
  "message": "ok",
  "data": { "itemId": 1 }
}
```

**路径参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `cohort_id` | int | 班次 ID |

| `consultContent` | string | 否 | 咨询内容 |

